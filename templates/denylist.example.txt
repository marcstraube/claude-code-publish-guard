#   [always]         applies to any published text
#   [messages-only]  applies to commit messages, PR/issue/release/comment bodies

# `\bjane\b` matches "jane" but not the public namespace "janedoe".
#
# A hit blocks the command hard; there is no override flag. If a pattern
# causes a false positive, reword the text or refine the pattern here.
